# Privacy and publication boundaries

This is a documentation-only GitHub repository. It does not accept survey submissions, store participant responses, or contain an administrative interface.

## Material intentionally excluded

- Individual survey submissions, written comments, exports, or participant identifiers.
- Database files, database connection information, or backups.
- Administrator passwords, session tokens, API keys, SSH keys, or other credentials.
- Hosting, deployment, server directories, usernames, or internal configuration.
- Private student or family records.

## Survey data

The community survey itself runs separately from this repository. Public summaries should use aggregated responses and disclose each question's response count. Personal details in comments should be removed before publication.

This document does **not** claim that the live survey is fully anonymous, that no technical logs exist, or that all aspects of live data collection have been independently audited. The survey website's privacy notice should explain actual collection, retention, access, and logging practices after those practices have been verified.

If you notice an error in the public documentation, contact Cardinal Oversight through its public website rather than submitting private personal information to GitHub.
